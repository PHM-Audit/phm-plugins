# PHM 物理校验 · 扣子(Coze)插件上架指南（点击级）

目标：把"物理合格证"插件挂进你的扣子智能体，让每次输出先过物理判定。

---

## 第 0 步：部署服务（一次性，约10分钟）

插件需要一个公网 HTTPS 地址。三个选项按上手难度排序：

**选项A：Hugging Face Spaces（免费，推荐）**
1. 打开 https://huggingface.co/new-space
2. Space name 填 `phm-physics-check`，SDK 选 **Docker**
3. 把本目录 `server/` 下三个文件（app.py / phm_lite.py / requirements.txt）+ 一个 `Dockerfile` 上传（内容见附录）
4. 等 Status 变 **Running**，记下地址：`https://你的用户名-phm-physics-check.hf.space`

**选项B：腾讯云 SCF / 任何支持 Docker 的平台**——上传同一套文件。

**选项C：本地内网穿透调试**（先试效果用）：
```bash
cd server && pip install -r requirements.txt
uvicorn app:app --port 8000
# 另开终端：cloudflared tunnel --url http://localhost:8000
```

---

## 第 1 步：在扣子里创建插件（5分钟）

1. 打开扣子 https://www.coze.cn → 左侧 **工作空间 → 资源库 → 新建资源 → 插件**
2. 创建方式选 **「基于OpenAPI导入」**（云侧导入）
3. 导入方式选 **「URL」**，填：`https://你的地址/openapi.yaml`（本目录 openapi.yaml 需先放到能访问的地方；或选「JSON/YAML编辑」把 openapi.yaml 内容整段粘贴进去）
4. 把 servers 里的 `https://YOUR-DEPLOYED-HOST/v1` 改成你第0步得到的真实地址
5. 点 **完成** —— 扣子会自动解析出 `physicsCheck` 工具

## 第 2 步：测试插件

1. 插件页 → **「测试」** 标签
2. 输入示例：
   ```json
   {"text": "The signal travels at 4.0e9 m/s. Confidence: 1.8."}
   ```
3. 预期返回：`verdict: FAIL`，violations 含 `speed_of_light` 和 `probability_out_of_range` 两条

## 第 3 步：挂进智能体

1. 你的智能体 → **技能 → 插件 → 添加** → 勾选 `PHM Physics Check`
2. 在人设与回复逻辑里加一句：
   > 生成含物理量的内容后，必须调用 phm_physics_check 工具；返回 FAIL 时，依据 violations 逐条修正后重新输出。
3. 发布。

## 第 4 步（可选）：上架插件商店

插件页 → **「提交审核」** → 按表单填写分类（开发者工具/教育）→ 审核通过后全站可搜。

## 附录：Dockerfile（选项A用）

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY server/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY server/ .
CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "7860"]
```

## 隐私与安全说明

- 服务无状态：不存储任何请求文本
- 上公网前建议在 app.py 加一个简单 token 校验（示例：请求头 `X-Token` 比对环境变量）
- 判定确定性可复算：同输入必同输出
